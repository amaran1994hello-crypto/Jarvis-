# JARVIS PROFESSIONAL AI - INSTALLATION GUIDE
Founder: **Amar**

## Quick Start
1. Extract ZIP: `unzip JARVIS_PROFESSIONAL_AI.zip`
2. Enter directory: `cd JARVIS_PROFESSIONAL_AI`
3. Setup virtualenv: `python3 -m venv venv && source venv/bin/activate`
4. Install packages: `pip install -r requirements.txt`
5. Configure keys: `cp .env.example .env`
6. Run: `python run.py`
